# 🎧 Cascaded FIR Audio Filter

This MATLAB project implements a **cascaded FIR (Finite Impulse Response) band-pass filter** for processing audio signals. Users can select an input audio file, configure filter parameters, apply multi-stage FIR filtering using various window functions, and visualize results in both time and frequency domains. The project also provides tools to analyze filtering performance and export the processed audio.

---

## 🚀 Features

- 📥 **Interactive Input**  
  - Lower and upper cutoff frequencies (Hz)  
  - Passband ripple (dB) and stopband attenuation (dB)  
  - Filter order (must be a positive odd number)

- 🧰 **Automatic Window Selection**  

  Based on user-specified ripple and attenuation:
  - Rectangular
  - Hanning
  - Hamming
  - Blackman

- 🧱 **Multi-Stage FIR Filter**  
  - Cascaded filter stages improve filtering efficiency
  - Customizable number of filter stages

- 📊 **Signal Visualization**  
  - Time-domain plots of original, noisy, and filtered signals  
  - Frequency-domain magnitude response (dB scale)  
  - Pole-zero diagram of the filter  
  - Impulse response plot

- 📉 **Noise Analysis**  
  - Noise signal extracted and visualized  
  - Noise reduction percentage calculated and displayed

- 💾 **Output Files**  
  - `filtered_audio.wav`: Filtered audio result  
  - `noisy_audio.wav`: Noisy (normalized) input audio

---

## 🛠 Requirements

- MATLAB (R2018 or later recommended)
- Signal Processing Toolbox
- `.wav` format audio file for input

---

## 🧪 How to Use

1. Clone or download this repository.
2. Open the main script in MATLAB.
3. Run the script and follow the command line prompts:
   - Select an audio file (`.wav`)
   - Enter desired filter parameters
4. View the plots generated by the script.
5. Check the output `.wav` files in the working directory.

---

## 📈 Output Visualizations

- **Time-Domain Plots**  
  - Original audio  
  - Noisy audio  
  - Filtered audio  

- **Frequency-Domain Plots**  
  - FFT magnitude (in dB) for all three signals

- **Impulse Response and Pole-Zero Plot**  
  - Visual insight into filter characteristics

- **Noise Removed Visualization**  
  - Difference between noisy and filtered signals
